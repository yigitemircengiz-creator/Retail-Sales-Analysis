# Retail-Sales-Analysis
This project was developed as a final capstone for the Kaggle Data Visualization course. It focuses on analyzing a retail sales dataset to identify profitability trends across different market categories and regions using Python's powerful visualization libraries.

## Project Overview
The primary goal of this analysis is to transform raw retail data into actionable business insights. By leveraging Seaborn and Matplotlib, the project visualizes net profit distribution to help stakeholders understand which product categories are driving growth.

## Key Features
- Data Integration: Loading and cleaning retail sales data with Pandas.
- Advanced Visualization: Custom-styled bar charts with precise data annotations.
- Professional Aesthetics: Utilization of modern color palettes (magma) and minimalist design principles (sns.despine).
- Insights: Identification of high-performing market categories.

## Tech Stack
- Python
- Pandas (Data Manipulation)
- Seaborn (Statistical Data Visualization)
- Matplotlib (Plotting and Aesthetics)

## Visualizations
The analysis includes a high-fidelity "Profitability Analysis Across Product Categories" dashboard which features:
- Clear data labels for exact profit values.
- Optimized layout for business presentations.
- Modern typography and color hierarchy.

## Dataset
The dataset used in this project includes information about:
- Product Categories (Electronics, Clothing, etc.)
- Sales and Quantity
- Net Profit
- Regional Data
